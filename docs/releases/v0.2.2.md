# 拾图 v0.2.2

修正漫画源网址导入的错误处理。

- 源清单导入超时由 30 秒调整为 90 秒，显示等待状态，支持取消。
- 区分超时、用户取消、连接中止及非 JSON 网页响应，避免暴露原始 IPC AbortError。
- 明确提示：网站首页不是源清单，需要符合 atelier-source-v1 的 JSON 地址，不能直接导入普通网站或 Venera JS。
- 支持带 UTF-8 BOM 的源 JSON。
- 18 项自动测试通过，并使用云端 Electron 验证网页误导入、取消、有效 JSON 网址导入以及原有阅读流程。

该修复不包含 ex.810114.xyz 的站点适配。该网站在云端仍返回 HTML 重定向，不能作为 JSON 源导入。
