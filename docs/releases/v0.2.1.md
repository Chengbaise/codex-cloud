# 拾图 v0.2.1

首个公开发布版本：支持自定义 JSON 漫画源的桌面漫画阅读器，提供黑色主题与作品名称模糊搜索。

## 功能

- 导入、切换、删除漫画源，支持 JSON 文件、HTTPS 清单和粘贴 JSON。
- 支持静态目录源及统一 JSON API 源。
- 按作品名称、作者或综合关键词搜索，提供包含、模糊、精确匹配。
- 单页与条漫阅读、章节切换、书架收藏及阅读进度保存。
- 整章顺序下载、进度查看、取消下载及文件定位。
- 保留网页浏览和右键单图下载。

## Windows 使用

下载 `Shitu-0.2.1-Windows-x64.zip`，完整解压，运行其中的 `拾图.exe`，保留同目录的运行时文件。可使用 `SHA256SUMS.txt` 校验下载完整性。

程序面向 Windows x64，构建未签名。无需另行安装 Node.js 即可运行打包版。

## 漫画源与验证范围

- 当前不兼容 Venera JS 源，没有内置第三方在线漫画站。内置「山间来信」为原创演示图。
- 普通网站首页需要转换成符合本项目协议的目录或 API 源；接入方法见仓库的 `docs/source-format.md`。
- API 源的搜索匹配语义由源端实现。
- 15 项自动测试、语法检查与 Linux 云端 Electron 桌面样本测试通过。尚未执行 Windows 交互式实机测试及第三方漫画站适配测试。
- 当前不支持下载断点续传、自动重试或应用内离线下载库。
